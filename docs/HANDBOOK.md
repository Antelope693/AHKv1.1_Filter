## 使用手册

### 快速开始

1. 安装 Python 3.10+ 与 AutoHotkey v1.1。
2. 在项目根目录执行 `pip install -r requirements.txt`。
3. 双击 `run.bat`（首次会请求管理员权限）。
4. 将脚本放入 `scripts/`：子文件夹 = 配置组；直接放在 `scripts/` 根目录 = 散装脚本。
5. 勾选需要的脚本，点击红色「未启动」按钮变为蓝色「运行中」。

### 界面说明

| 控件 | 作用 |
|------|------|
| 启停按钮 | 红色=未启动（点击启动），蓝色=运行中（点击终止） |
| 启停热键 | 录制全局启停组合键 |
| TEST | 展开内嵌输入栏，方便验证脚本键鼠行为 |
| 手册 | 公告 / 使用说明 / 更新记录，并可检测新版本 |
| 列表右侧刷新图标 | 仅在全局终止后可重新扫描 `scripts/` |

### 配置组

- 每个 `scripts/<组名>/` 是一个配置组，默认折叠。
- 组头「全选」可一键勾选组内全部脚本。
- 散装脚本显示在所有配置组下方。
- 默认全部未勾选。

### 热更新

- 手册窗口可检测 GitHub Release。
- 更新会覆盖程序代码，**保留** `scripts/` 与 `ahk_filter_config.json`（勾选状态、热键、折叠状态等）。
